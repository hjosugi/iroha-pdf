# Security policy

Every build published on
[GitHub Releases](https://github.com/hjosugi/iroha-pdf/releases), including the
latest, is an unsigned engineering preview: there is not yet a signed,
notarized, physical-device-verified production release line. What still blocks
one is listed in [docs/RELEASE_GATE.md](docs/RELEASE_GATE.md).

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/hjosugi/iroha-pdf/security/advisories/new).
Do not attach confidential PDFs, credentials, OAuth tokens, or signing material
to public issues. Include a minimal synthetic reproducer whenever possible.

The current threat model and known limitations are documented in
[docs/PRIVACY_SECURITY.md](docs/PRIVACY_SECURITY.md).
